# Human Typer 🧑‍💻

Human Typer simulates realistic human typing in Visual Studio Code.
Perfect for coding tutorials, demos, and screen recordings.

## ✨ Features
- Human-like typing with random delays
- Smart pauses after `{ } ;` and new lines
- Type from clipboard or file
- Adjustable speed via Settings
- Stop typing anytime
- Optional mistake simulation

## 🚀 Commands
- **Human Typer: Type Clipboard**
- **Human Typer: Type From File**
- **Human Typer: Stop Typing**

## ⚙️ Settings
Search `Human Typer` in VS Code settings to configure:
- Typing speed
- Smart pauses
- Line-by-line mode
- Mistake simulation
